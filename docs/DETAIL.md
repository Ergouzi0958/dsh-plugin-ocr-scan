# 扫描件转 Markdown

把书本扫描页、拍照页拖进来，生成一份可直接导入 Obsidian 的 Markdown 文档。

## 用法

1. 在对话输入框下方找到「扫描件转 Markdown」条，点开
2. 拖入页面图片，或按 `Ctrl+V` 粘贴
3. 选模型、填书名，点**开始识别**
4. 完成后：

```
输出目录/
  <书名>.md          正文，每页配原图
  原书页-图册.md      按页翻的原图册
  images/page-195.jpg ...
```

## 关于 API Key（重要）

**预设模型不包含密钥。** 面板里的三个预设只是预填了「模型 ID + 接口地址」，Key 必须用你自己的：

| 填入位置 | 说明 |
|---|---|
| 面板 → 齿轮 → API Key | 存在本机浏览器，刷新、重启都不用重填 |
| 插件设置 `apiKey` | 所有会话共用 |
| 环境变量 `OCR_SCAN_API_KEY` | 同上，适合脚本 |

插件是开源分发的，**不会也不应该内置任何人的密钥**。

## 自动排页序

扫描件的顺序常常是错的（相邻两页互换、跳页）。插件用两步还原：

1. **读页眉页码** —— 页码印在页眉左右两端（偶数页在左、奇数页在右）。面板把两端各裁一块放大后交给模型单独识别，只接受纯数字；读到「件」「The number 1」这类噪声一律丢弃。
2. **正文接续校验** —— 相邻两页如果接不上，就尝试和下一页交换，用二元组重合度判断。

没有印页码的书（讲义、手稿）退回扫描顺序。

## 排版处理

| 问题 | 处理 |
|---|---|
| 页眉混进正文 | 剥离「第九章 … ·195·」这类行 |
| 标题层级乱 | 第X节 → `##`，「一、」→ `###`，「1.」→ `####` |
| 表格渲染不出来 | 补 `|---|` 分隔行、表前后空行、列数对齐 |
| 段落粘成一坨 | 非表格行之间补空行 |
| 模型编造图片链接 | 清掉 `via.placeholder.com` / `image.png` 假引用，改用每页原图 |

## 模型

面板里可切换，齿轮里可增删：

- **混元 OCR** `xophunyuanocr` —— 默认。标题层级自带，稳定不失控
- **PaddleOCR-VL** `xoppaddleocrv16` —— 文字量大，会输出表格且可能失控
- **DeepSeek-OCR** `xopdeepseekocr`
- **自定义** —— 填模型 id、接口地址即可接入任何 OpenAI 兼容服务，存在本机浏览器

## 界面说明

- 面板挂在输入框下方，**点开后是浮层窗口**，不挤占对话区
- 点击遮罩空白、按 `Esc`、点 ✕ 都能关闭
- 次级页面左上角 `‹` 返回
- 浮层内滚轮只滚浮层，不会带动背后的聊天

## 配置项

- `endpoint` 接口地址
- `model` 模型 id
- `apiKey` 密钥
- `outputDir` 输出目录；留空写到 `ocr-scan/` 下

## 限制

- 需要联网，页面图片会上传到所选服务商。**受版权保护或内部资料请自行确认是否可以上传。**
- 逐页识别，40 页约 2~4 分钟。
- OCR 本身仍有错字（「巧」常是 5、「佣」常是 00），需人工校对。
- 页序靠页眉页码；整页没有印刷页码时无法自动排序。
